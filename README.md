# Tomatoes & Transistors

Welcome to the source code for **Tomatoes & Transistors**—my personal corner of the web where garden dirt meets circuit boards. 

I started messing with computers back in the 1980s (GW-BASIC, DOS, and C64s), worked on F-15 and F-16 avionics in the Air Force, and turned wrenches for years before heading back to college full-time for Computer and Information Systems. This site is my digital workshop for logging tech builds, coding experiments, and organic gardening.

## What's Under the Hood
No bloated frameworks—just clean code built from scratch in VS Code:
* **HTML, CSS & Vanilla JavaScript:** Custom dark-terminal aesthetic with a responsive dashboard card layout.
* **Patch:** My interactive AI mascot and site knowledge assistant running in the workshop console.
* **Custom Media Player:** A reskinned YouTube API player featuring a searchable pop-up playlist.
* **Live Telemetry & RSS:** Status bar and live feeds tracking active projects, coursework, and garden logs.

## Site Map
* **Home:** Main dashboard, telemetry bar, and project cards.
* **Technology:** Hardware tinkering, code builds, and AI experiments.
* **Growth:** Gardening logs, soil notes, and plant care.
* **Journey:** The road from microfiche and soldering irons to modern IT.
